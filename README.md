# Todo API

Простой REST API для списка задач на Go и фреймворке [Echo](https://echo.labstack.com). Учебный проект: создание, просмотр и удаление задач с проверкой входных данных и корректными HTTP-статусами.

## Стек

- **Go**
- **Echo v4** — HTTP-фреймворк
- Хранение данных в памяти (слайс)

## Возможности

- Получение списка задач
- Создание задачи с проверкой названия
- Удаление задачи по `id`
- Уникальные `id`, которые не повторяются после удаления задач
- Обрезка пробелов по краям названия, отклонение пустых названий
- Логирование всех запросов
- Понятное сообщение об ошибке, если сервер не смог запуститься (например, порт занят)

## Модель задачи

```json
{
  "id": "1",
  "title": "Купить хлеб",
  "done": false
}
```

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | уникальный идентификатор, выдаётся сервером |
| `title` | string | название задачи |
| `done` | bool | выполнена ли задача |

## Эндпоинты

| Метод | Путь | Описание | Успешный ответ |
|---|---|---|---|
| `GET` | `/tasks` | список всех задач | `200 OK` |
| `POST` | `/tasks` | создать задачу | `201 Created` |
| `DELETE` | `/tasks/:id` | удалить задачу | `204 No Content` |

### `GET /tasks`

Возвращает все задачи.

**Ответ `200 OK`:**
```json
[
  {"id": "1", "title": "Купить хлеб", "done": false},
  {"id": "2", "title": "Выучить Go", "done": true}
]
```

### `POST /tasks`

Создаёт новую задачу. Пробелы по краям названия обрезаются.

**Тело запроса:**
```json
{"title": "Погулять"}
```

**Ответ `201 Created`:**
```json
{"id": "3", "title": "Погулять", "done": false}
```

**Ошибки:**

| Статус | Когда | Тело ответа |
|---|---|---|
| `400 Bad Request` | некорректный JSON | `{"error": "неверный JSON"}` |
| `400 Bad Request` | пустое название или только пробелы | `{"error": "пустой title"}` |

### `DELETE /tasks/:id`

Удаляет задачу с указанным `id`.

**Ответ `204 No Content`** — без тела.

**Ошибки:**

| Статус | Когда | Тело ответа |
|---|---|---|
| `404 Not Found` | задачи с таким `id` нет | `{"error": "задача не найдена"}` |

## Запуск

```bash
git clone <ссылка-на-репозиторий>
cd todo
go mod tidy
go run main.go
```

Сервер запустится на `http://localhost:8080`.

## Примеры запросов

### curl

```bash
# Список задач
curl http://localhost:8080/tasks

# Создать задачу
curl -X POST http://localhost:8080/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Погулять"}'

# Удалить задачу
curl -X DELETE http://localhost:8080/tasks/1
```

### PowerShell 7

```powershell
# Список задач
Invoke-RestMethod http://localhost:8080/tasks

# Создать задачу
Invoke-RestMethod -Method Post -Uri http://localhost:8080/tasks -ContentType "application/json" -Body '{"title":"Погулять"}'

# Удалить задачу
Invoke-RestMethod -Method Delete -Uri http://localhost:8080/tasks/1
```

## Ограничения

- Данные хранятся в памяти и пропадают после перезапуска сервера.
- Хранилище не защищено от одновременных запросов (нет мьютекса).
